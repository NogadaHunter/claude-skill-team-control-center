  • 비용은 Claude API 공식 단가로 계산한 환산값이에요. 구독 요금제로 쓰면 실제 청구액이 아니에요. 단가·환율·월 예산은 config/pricing.json에서 고쳐요.
  • 직원 토큰은 직원(서브에이전트)이 쓴 기록만 정확히 센 값이에요. 스킬 토큰은 스킬을 부른 뒤 다음 요청까지 쓴 토큰을 그 스킬 몫으로 본 추정값이에요.
  • 실시간 상태는 2초마다 갱신돼요. 승인 대기는 3D 사무실 훅이 있어야 알 수 있어요.
  • claude.ai 웹·앱에서 쓴 스킬은 이 PC 기록에 없어서 빠져요.
  • 직원의 목적·목표·워크플로는 config/profiles.json, 맡은 스킬은 ~/.claude/agents/*.md 표에서 읽어요.
